技能操作示範

animate：用 Claude 寫程式做動畫短片

不用 AI 生影片、不用動畫軟體。Claude 把每個字、每根長條都寫成程式，一格一格畫出來，最後輸出 MP4。文字清楚、數字準確，哪裡不對只改那一處。

為什麼這樣做 入門：免費網頁版 中階：桌面版 進階：animate 工具包 組合技 提示詞範本 外國資源簡介 熱門提示詞選讀 換電腦與疑難排解

先搞懂：這跟「AI 生成影片」差在哪

AI 生成影片

模型直接生出整段畫面，像真的，但畫面上的字常常模糊、數字可能對不上。適合真人、實拍感的場景。

Claude 寫程式做動畫

字、數字、圖形都是程式畫的，你給什麼數字就是什麼數字，改一處不會牽動其他處。做不到真人與實拍場景。

適合：簡報動態圖表、行銷短片、概念說明、年表與歷史、教學說明動畫。

官方的 Claude Motion 目前只開放給團隊與企業方案。下面三種做法不需要它，三個階段的難度與需求逐級增加。
入門中階進階
用什麼Claude 網頁版Claude 桌面版的 Code 分頁桌面版＋animate 工具包

1

入門：免費網頁版，一句話拿到 MP4

對應影片 2:35–5:40｜不用安裝任何東西

  1. 登入網頁版 Claude。免費帳號即可，預設模型就能做。
  2. 把資料交給它。把表格檔拖進對話框，或按左下角「＋」選上傳檔案。資料直接附檔，比叫它上網找更不容易出錯。
  3. 打一句話，講清楚三件事：給它什麼資料、影片幾秒、畫面尺寸；最後加一句「給我 MP4 檔」。
  4. 等它做。它會讀表格、算數字、寫程式、畫畫面，畫完還會自己檢查（影片示範中它自己發現大數字太靠邊並修好）。示範約 3 分鐘。
  5. 下載。對話框右側出現播放器，右上角有下載鍵，得到一般 MP4。
  6. 放進簡報。PowerPoint：插入 → 視訊。Google 簡報：先傳到 Google 雲端硬碟，再插入 → 影片。

範例提示詞（改成你的資料）

把附件這份營收表做成一支 30 秒的動態報告影片，長條圖一根一根長出來，最後停在最新一季的數字並標出成長倍數。 尺寸 1920×1080，畫面文字用繁體中文，最後給我 MP4 檔。
網頁版附件有大小限制（影片示範提到單檔不超過 30MB），要處理一堆檔案請改用中階。
2

中階：桌面版，直接讀你的資料夾

對應影片 5:41–10:20｜用資料夾工作，做好的檔案直接存回去

跟網頁版最大的差別：不用一個一個上傳下載，它直接讀資料夾，成品也存回同一個資料夾。幾天後想改，開同一個資料夾再說一次就好。

  1. 安裝桌面版 Claude。官網下載，Mac、Windows 都有，用平常的帳號登入。Code 分頁需要付費方案。
  2. 準備一個資料夾。放進這次要用的資料（營收表、商品照、標誌、參考設計）。
  3. 開新對話：點上方「Code」→ 新對話 → 對話框左邊「＋」→ Add folder → 選剛才的資料夾。對話框下方出現資料夾名稱，代表它看得到檔案。
  4. 打需求。第一次它讀寫檔案、執行程式前會詢問，看清楚它要做什麼再按允許。
  5. 不滿意就在同一個對話指定修改處。它改的是資料夾裡同一份程式，改完重新輸出，不用從頭來。

範例提示詞：15 秒 IG 限時動態

做一支 15 秒的直式 IG 限時動態（1080×1920）。 資料只有這四項：品名「桂花烏龍拿鐵」、「秋季新品」、「11/1 上市」、「第二杯半價」。 畫面上的文字只能用這四項，不要自己增加任何文字。要有配樂，最後給我 MP4。
一定要加「文字只能用這四項」。影片作者第一次試時，AI 自己多寫了沒給的內容，沒注意就發出去會出事。

修改範例

優惠那行字再大一點，背景換成暖一點的顏色，改完重新輸出 MP4。
小技巧：有想要的感覺，就把喜歡的海報、以前做過的設計存進同一個資料夾，跟它說「參考這些的風格」，成品會更接近。
3

進階：animate 工具包，換出特定畫風

對應影片 10:55–16:30｜原作者 cth9191，GitHub：cth9191/animate（MIT）

只給一句話，Claude 通常做出「會動的投影片」。animate 把七種畫風的畫法與一套固定製作流程寫成技能，Claude 照著做，就能做出剪紙、版畫、像素那種有風格的作品。

七種內建畫風

畫風長相
剪紙（cut paper）撕紙、陰影、蠟筆、有臉的角色
交叉線墨水（crosshatch）版畫插圖感，線條會抖動，暖紙色
孔版印刷（riso）三色油墨、網點、套色偏移
素描本（sketchbook）鉛筆灰加一個重點色，手寫字
數學風（math）黑底、座標圖形、顏色對應變數
像素（pixel）低解析度，不同年代的畫面
等角線稿（isometric）精準的等角線條，一個深色重點

也可以給它參考圖（影片、截圖、網頁），它會量出配色、線條粗細、質感與節奏，先畫一兩張跟參考圖並排比對，你點頭後存成自己的畫風。

步驟一：安裝（每台電腦各一次）

安裝前請先確認安全。外掛可以讓 Claude 在你的電腦上做事，只加信任的來源。最簡單的方法：請 Claude Code「幫我看一下這個工具包有沒有可疑或危險的動作」，確認沒問題再同步。原作者隨時可能更新內容，所以每次安裝前都建議再確認。

方法 A：桌面版畫面操作（影片示範的做法）

  1. 桌面版切到 Code，按對話框左邊「＋」→ Plugins → Browse plugins。
  2. 右上角 Add → Add marketplace → Add from a repository。
  3. 網址欄輸入 cth9191/animate（要用自己的備份版就輸入 andice0107/animate）。
  4. 看完安全提醒、檢查沒問題後按 Sync。清單出現 Animate，右下角跳出「已安裝」提示。
  5. 回到對話框輸入 /，清單看得到 animate 就成功了，之後每個新對話都能用。

方法 B：指令

/plugin marketplace add andice0107/animate /plugin install animate@animate

方法 C：手動複製：把 repo 裡 plugins/animate/skills/animate/ 整個資料夾複製到 ~/.claude/skills/animate/。

步驟二：補齊環境

工具包要靠幾個小程式把畫面輸出成影片：Node 18 以上、ffmpeg、Playwright 與 Chromium。第一次用時如果它說少了什麼，直接跟它說「幫我裝好」，跳出詢問時按允許。要自己裝：

npm i -g playwright && npx playwright install chromium

要做旁白才需要另外裝 Python 的 faster-whisper（算每個字的時間），聲音可用 ElevenLabs 連接器，或用自己的錄音。

步驟三：發動

開新對話、選好資料夾，輸入 /animate 加上題目：

/animate 用 30 秒講完 4 萬年藝術史，從洞穴壁畫一路到今天，中間穿插一隻黃金獵犬出現在每個時代的畫裡，畫風用交叉線墨水

它不會馬上開工，流程是：

關卡你會看到你要做的
0 問答題目、格式、旁白、畫風、主角、音樂、是否放產品圖，附畫風選項與推薦回答；不知道怎麼選就選它推薦的
1 故事大綱編號的拍點表（每幾秒演什麼），事實會上網核對同意或修改
2 畫風樣張2–4 張全尺寸靜態畫面每張點頭或要求調整
3 分鏡整支片排成一張大圖，含聲音與轉場依面板編號回覆好或不好
4 製作寫程式、畫畫面、自己做配樂不用盯著，可離開做別的事
5 交付影片＋量測檢查：切換有沒有對準節拍、字有沒有被切掉、音量、旁白速度看完給意見，會再修一輪
這三關（故事、畫風、分鏡）最值得認真看，在這裡改，比做完再改省事很多。影片示範的 4 萬年藝術史大約 40 分鐘完成，用掉 Max 帳號一週額度約 1%。

作品會建立在你的專案資料夾 pieces/作品名/ 底下，可輸出 9:16、1:1、4:5、16:9，每種版面是重新排版而不是裁切。

組合技：搭配目錄裡其他技能

animate 負責「動起來」，其他技能負責「內容正確」。下面是幾種搭法（技能名稱都能在目錄查到）。

想做的事搭法
成語說明動畫先用成語教學類技能確認成語意思與例句，再把確認過的文字交給 animate，並要求「畫面文字只用我給的這些」。
課文或單元複習短片把課本截圖或整理好的重點放進資料夾，請 animate 依重點排拍點，配 guoyu-vocab-animated-reader 之類的點讀教材當課後練習。
社會技巧情境情境與題目由 social-scenario-animated-reader 這類技能產出，需要影片版時再交給 animate 做成短片。
簡報裡的動態圖表入門做法產出 MP4，再請 Claude 把影片插進指定頁的標題下方。檔案太大時，改成自己插。
要真人或實拍感animate 做不到，改用目錄裡的 colab-video-gen 之類 AI 生成影片，兩者可剪在一起。
多尺寸發布同一個作品一次輸出直式、方形、橫式，貼到不同平台。
做給學生看的教材，請先把事實、字詞、注音再核對一次，AI 的自我檢查不能取代老師把關。

三張可直接改的提示詞範本

原則都一樣：資料、秒數、尺寸講清楚，最後要 MP4。下列是依影片提出的原則改寫的版本，把方括號換成你自己的內容。

① 簡報數據

把附件的 [資料名稱] 做成一支 [30] 秒的動態報告影片，[長條圖／折線圖] 依序出現，結尾標出 [重點數字]。 尺寸 [1920×1080]，畫面文字用繁體中文，數字必須與附件完全一致，最後給我 MP4 檔。

② 行銷短片

做一支 [15] 秒的 [直式 1080×1920] 短片，宣傳 [產品名稱]。 畫面文字只能用這幾項：[品名]、[賣點]、[日期]、[優惠]，不要自己增加文字。 風格參考資料夾裡的 [參考圖]，要有配樂，最後給我 MP4 檔。

③ 概念解說（先看分鏡再動手）

用 [60] 秒解釋 [概念]，給 [國小三年級] 的學生看，畫面文字用繁體中文。 先給我看分鏡（每一段演什麼、幾秒），我確認之後再開始做，最後給我 MP4 檔。

第③張的「先給我看分鏡」這句，讓你就算沒裝工具包，也能先看過再讓它動手。

換電腦、換 agent 能用嗎？疑難排解

只貼提示詞行不行？

入門與中階可以：提示詞是一般文字，任何有 Claude 的地方都能貼。進階不行：/animate 是安裝在電腦上的技能，每台電腦都要各裝一次外掛與環境（Node、ffmpeg、Playwright）。

  • 只有支援 Claude Code 技能格式的 agent 能用；Gemini、ChatGPT 與雲端版 Claude 沒有本機的瀏覽器與 ffmpeg，無法渲染。
  • 其他 agent 若要借用，可把技能資料夾整份交給它讀 SKILL.md，但渲染環境仍然要有。

常見問題

  • 說找不到 playwright：跑工具時加上 NODE_PATH=$(npm root -g)，或請 Claude 代為處理。
  • 工具參數順序：截圖工具 still.mjs 的順序是「作品資料夾、時間點、輸出檔」。
  • riso（孔版印刷）範例在 2 秒處報錯 createRadialGradient：2026-11-21 實測內建 riso demo 會出現，尚未查明原因；其他風格的範例（如剪紙的 history-of-ai）渲染正常，遇到可先換畫風。
  • 它自己多寫了不該有的文字：在提示詞明講「畫面文字只能用我給的這些」。
  • 做出來像會動的投影片：沒有用到工具包，或沒有指定畫風，改用 /animate 並選畫風。

三個心得

  1. 真正花時間的是把需求講清楚。資料、秒數、尺寸都講好，常常一次就過。
  2. 第一版不用太在意，在同一個對話叫它改，通常兩三輪就會是你要的樣子。
  3. 它會自己檢查，但最後一關要你把關，放進正式簡報或教材前，數字與文字務必自己再對一次。
