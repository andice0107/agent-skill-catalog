技能操作示範

animate：用 Claude 寫程式做動畫短片

不用 AI 生影片、不用動畫軟體。Claude 把每個字、每根長條都寫成程式，一格一格畫出來，最後輸出 MP4。文字清楚、數字準確，哪裡不對只改那一處。

為什麼這樣做 入門：免費網頁版 中階：桌面版 進階：animate 工具包 教學現場提示詞 組合技 提示詞範本 外國資源簡介 熱門提示詞選讀 換電腦與疑難排解

先搞懂：這跟「AI 生成影片」差在哪

AI 生成影片

模型直接生出整段畫面，像真的，但畫面上的字常常模糊、數字可能對不上。適合真人、實拍感的場景。

Claude 寫程式做動畫

字、數字、圖形都是程式畫的，你給什麼數字就是什麼數字，改一處不會牽動其他處。做不到真人與實拍場景。

適合：簡報動態圖表、行銷短片、概念說明、年表與歷史、教學說明動畫。

官方的 Claude Motion 目前只開放給團隊與企業方案。下面三種做法不需要它，三個階段的難度與需求逐級增加。

1

入門：免費網頁版，一句話拿到 MP4

對應影片 2:35–5:40｜不用安裝任何東西

  1. 登入網頁版 Claude。免費帳號即可，預設模型就能做。
  2. 把資料交給它。把表格檔拖進對話框，或按左下角「＋」選上傳檔案。資料直接附檔，比叫它上網找更不容易出錯。
  3. 打一句話，講清楚三件事：給它什麼資料、影片幾秒、畫面尺寸；最後加一句「給我 MP4 檔」。
  4. 等它做。它會讀表格、算數字、寫程式、畫畫面，畫完還會自己檢查（影片示範中它自己發現大數字太靠邊並修好）。示範約 3 分鐘。
  5. 下載。對話框右側出現播放器，右上角有下載鍵，得到一般 MP4。
  6. 放進簡報。PowerPoint：插入 → 視訊。Google 簡報：先傳到 Google 雲端硬碟，再插入 → 影片。

範例提示詞（改成你的資料）

把附件這份營收表做成一支 30 秒的動態報告影片，長條圖一根一根長出來，最後停在最新一季的數字並標出成長倍數。 尺寸 1920×1080，畫面文字用繁體中文，最後給我 MP4 檔。
網頁版附件有大小限制（影片示範提到單檔不超過 30MB），要處理一堆檔案請改用中階。
2

中階：桌面版，直接讀你的資料夾

對應影片 5:41–10:20｜用資料夾工作，做好的檔案直接存回去

跟網頁版最大的差別：不用一個一個上傳下載，它直接讀資料夾，成品也存回同一個資料夾。幾天後想改，開同一個資料夾再說一次就好。

  1. 安裝桌面版 Claude。官網下載，Mac、Windows 都有，用平常的帳號登入。Code 分頁需要付費方案。
  2. 準備一個資料夾。放進這次要用的資料（營收表、商品照、標誌、參考設計）。
  3. 開新對話：點上方「Code」→ 新對話 → 對話框左邊「＋」→ Add folder → 選剛才的資料夾。對話框下方出現資料夾名稱，代表它看得到檔案。
  4. 打需求。第一次它讀寫檔案、執行程式前會詢問，看清楚它要做什麼再按允許。
  5. 不滿意就在同一個對話指定修改處。它改的是資料夾裡同一份程式，改完重新輸出，不用從頭來。

範例提示詞：15 秒 IG 限時動態

做一支 15 秒的直式 IG 限時動態（1080×1920）。 資料只有這四項：品名「桂花烏龍拿鐵」、「秋季新品」、「11/1 上市」、「第二杯半價」。 畫面上的文字只能用這四項，不要自己增加任何文字。要有配樂，最後給我 MP4。
一定要加「文字只能用這四項」。影片作者第一次試時，AI 自己多寫了沒給的內容，沒注意就發出去會出事。

修改範例

優惠那行字再大一點，背景換成暖一點的顏色，改完重新輸出 MP4。
小技巧：有想要的感覺，就把喜歡的海報、以前做過的設計存進同一個資料夾，跟它說「參考這些的風格」，成品會更接近。
3

進階：animate 工具包，換出特定畫風

對應影片 10:55–16:30｜原作者 cth9191，GitHub：cth9191/animate（MIT）

只給一句話，Claude 通常做出「會動的投影片」。animate 把七種畫風的畫法與一套固定製作流程寫成技能，Claude 照著做，就能做出剪紙、版畫、像素那種有風格的作品。

七種內建畫風

畫風長相
剪紙（cut paper）撕紙、陰影、蠟筆、有臉的角色
交叉線墨水（crosshatch）版畫插圖感，線條會抖動，暖紙色
孔版印刷（riso）三色油墨、網點、套色偏移
素描本（sketchbook）鉛筆灰加一個重點色，手寫字
數學風（math）黑底、座標圖形、顏色對應變數
像素（pixel）低解析度，不同年代的畫面
等角線稿（isometric）精準的等角線條，一個深色重點

也可以給它參考圖（影片、截圖、網頁），它會量出配色、線條粗細、質感與節奏，先畫一兩張跟參考圖並排比對，你點頭後存成自己的畫風。

步驟一：安裝（每台電腦各一次）

安裝前請先確認安全。外掛可以讓 Claude 在你的電腦上做事，只加信任的來源。最簡單的方法：請 Claude Code「幫我看一下這個工具包有沒有可疑或危險的動作」，確認沒問題再同步。原作者隨時可能更新內容，所以每次安裝前都建議再確認。

方法 A：桌面版畫面操作（影片示範的做法）

  1. 桌面版切到 Code，按對話框左邊「＋」→ Plugins → Browse plugins。
  2. 右上角 Add → Add marketplace → Add from a repository。
  3. 網址欄輸入 cth9191/animate（要用自己的備份版就輸入 andice0107/animate）。
  4. 看完安全提醒、檢查沒問題後按 Sync。清單出現 Animate，右下角跳出「已安裝」提示。
  5. 回到對話框輸入 /，清單看得到 animate 就成功了，之後每個新對話都能用。

方法 B：指令

/plugin marketplace add andice0107/animate /plugin install animate@animate

方法 C：手動複製：把 repo 裡 plugins/animate/skills/animate/ 整個資料夾複製到 ~/.claude/skills/animate/。

步驟二：補齊環境

工具包要靠幾個小程式把畫面輸出成影片：Node 18 以上、ffmpeg、Playwright 與 Chromium。第一次用時如果它說少了什麼，直接跟它說「幫我裝好」，跳出詢問時按允許。要自己裝：

npm i -g playwright && npx playwright install chromium

要做旁白才需要另外裝 Python 的 faster-whisper（算每個字的時間），聲音可用 ElevenLabs 連接器，或用自己的錄音。

步驟三：發動

開新對話、選好資料夾，輸入 /animate 加上題目：

/animate 用 30 秒講完 4 萬年藝術史，從洞穴壁畫一路到今天，中間穿插一隻黃金獵犬出現在每個時代的畫裡，畫風用交叉線墨水

它不會馬上開工，流程是：

關卡你會看到你要做的
0 問答題目、格式、旁白、畫風、主角、音樂、是否放產品圖，附畫風選項與推薦回答；不知道怎麼選就選它推薦的
1 故事大綱編號的拍點表（每幾秒演什麼），事實會上網核對同意或修改
2 畫風樣張2–4 張全尺寸靜態畫面每張點頭或要求調整
3 分鏡整支片排成一張大圖，含聲音與轉場依面板編號回覆好或不好
4 製作寫程式、畫畫面、自己做配樂不用盯著，可離開做別的事
5 交付影片＋量測檢查：切換有沒有對準節拍、字有沒有被切掉、音量、旁白速度看完給意見，會再修一輪
這三關（故事、畫風、分鏡）最值得認真看，在這裡改，比做完再改省事很多。影片示範的 4 萬年藝術史大約 40 分鐘完成，用掉 Max 帳號一週額度約 1%。

作品會建立在你的專案資料夾 pieces/作品名/ 底下，可輸出 9:16、1:1、4:5、16:9，每種版面是重新排版而不是裁切。

教學現場提示詞：直接複製就能開工

這一區是為資源班教學預先設計的提示詞。每一則都已經把流程排好：先分析教材 → 提出規劃給你確認 → 你同意後才生成影片。貼進新對話（Claude Code，已選好資料夾、已裝好 animate）就會發動技能。方括號 [ ] 的地方換成你的內容，用不到的行直接刪掉。

使用前先看這四點

  1. 用「學生能力描述」決定難易度。不寫學生姓名，只寫能力，例如：「識字量約低年級、需要注音、一次只能專注一個重點、句子要短、喜歡動物」。Claude 會依此決定字幕大小、速度、句長、重複次數與畫面複雜度。
  2. 教材附在資料夾裡。課本頁面照片、語詞表、例句、解法、題目都放進對話選的資料夾，並在提示詞寫出檔名。學生姓名、學校名稱不要放進檔案。
  3. 每個「確認關卡」都要看。在規劃階段改，比做完再改省很多時間。想換方向，直接回覆修改意見即可。
  4. 成品上課前老師要把關。釋義、例句、注音、數字、解題步驟都請自己再核對一次，AI 的自我檢查不能取代老師。
畫面注音與特殊字形有時會畫錯，影片完成後請逐字看過。如果注音很重要，在提示詞裡加一句「注音一律以教育部標準為準，不確定的字先列出來讓我確認」。

難易度怎麼設定（可直接放進「學生能力描述」）

能力情況可以這樣寫影片會怎麼設計
識字少、閱讀吃力識字量低、需要注音、句子要很短、需要圖像與重複字大、有注音、每畫面一個重點、同一句重複兩次、多用圖示與動作
能讀短句、理解較慢能讀短句、抽象概念要用生活例子、一次一個重點先生活情境再講概念，句子短，關鍵詞用顏色標出，節奏放慢
基礎尚可、需要整理與延伸能讀一般課文、需要整理重點與舉一反三可有比較、歸納與小測驗，節奏正常，有延伸例子

① 國語：單一語詞（2～4 字，含成語）

約 1 分鐘以內。內容：語詞介紹（含意、用法、何時用）、情境故事、範例句子。不需要那麼久就縮短。

/animate 做一支國語語詞教學短片，語詞是「[語詞，例如：小心翼翼]」。 【學生能力】[例：識字量約低年級、需要注音、一次只能專注一個重點、句子要短、喜歡動物] 【影片內容】依序是：1）語詞是什麼（含意）；2）什麼時候用、怎麼用（用法）；3）一段短情境故事，讓學生看到這個語詞用在哪；4）2～3 個範例句子，句子難度符合上面的學生能力；5）一個小結。 【長度】最長 1 分鐘，內容不需要就縮短，不要硬湊。 【規格】16:9，畫面文字用繁體中文，語詞與關鍵字要大而清楚，注音標示正確；無旁白，用字幕與配樂；風格 [剪紙／素描本／由你推薦]。 【釋義依據】以教育部《重編國語辭典修訂本》為準；不確定的地方列出來讓我確認，不要自己編。 【流程】請依序：先給我「分析」（語詞的含意、常見用法與易混淆處、你建議的教學重點與情境），等我確認；再給我拍點表、畫風樣張與分鏡，等我確認；我說可以之後才開始製作。最後給我 MP4。

② 國語：一課的語詞（多個語詞、可附教材）

先放教材（語詞表、解釋、例句、課文）到資料夾，Claude 會先整理再規劃。每個語詞最多約 1 分鐘，可更短。

/animate 我要做一課的國語語詞教學影片。教材在資料夾裡：[檔名，例如：第三課語詞表.pdf、課文照片.jpg]。 【學生能力】[能力描述，不寫姓名] 【我提供的內容】[語詞表／語詞解釋／例句／課文／其他教材，沒有的行刪掉] 【每個語詞的結構】語詞介紹（含意、用法、何時用）、情境故事、範例句子；沒有需要的部分可以省略，每個語詞最多 1 分鐘。 【規格】全課做成一支影片，語詞之間用清楚的轉場，結尾做一個全課複習；16:9，畫面文字用繁體中文，注音標示正確；[有／無] 旁白。 【流程】請依序： 1）先分析我給的教材：列出所有語詞、你看到的難點（例如多音字、形近字、抽象詞）、哪些語詞適合用動畫情境，並指出教材裡不清楚或可能有誤的地方； 2）依學生能力提出影片規劃：哪些語詞要詳細、哪些簡單帶過、順序、每個語詞大約幾秒，以及整體畫風建議； 3）等我確認後，再給我拍點表、畫風樣張、分鏡，逐關等我確認； 4）全部確認後才開始製作，最後給我 MP4。 在我確認前，請不要開始製作影片。

③ 數學：讓學生更容易理解課本的概念與解法

先放教材（概念說明、例題、課本的解法），Claude 先分析，再規劃怎麼用動畫讓概念更清楚。

/animate 我要做一支數學概念教學影片，單元是「[單元名稱，例如：三位數加法進位]」。教材在資料夾裡：[檔名，例如：課本第 42～45 頁照片.jpg、習作題目.pdf]。 【學生能力】[例：能做簡單計算但不理解為什麼要進位、需要具體圖像、步驟要一步一步慢慢來、容易分心] 【我提供的內容】[數學概念說明／例題／課本的解法／常見錯誤，沒有的行刪掉] 【目標】用學生更容易理解的方式，把課本要教的概念與做法講清楚：用具體圖像或操作動畫呈現「為什麼這樣算」，再帶出課本的步驟，最後用 1～2 題做示範。 【規格】16:9，每個畫面一個重點，數字與符號大而清楚，關鍵步驟用顏色標示，數字必須與我提供的題目完全一致，畫面文字用繁體中文；[有／無] 旁白；風格 [數學風／剪紙／由你推薦]。 【流程】請依序： 1）先分析教材：這個單元的核心概念、先備知識、課本的解法步驟、學生可能的迷思與常見錯誤； 2）提出「怎麼讓學生看懂」的規劃：用什麼具體比喻或圖像、分幾個段落、每段多長、示範題選哪一題，並說明和課本解法怎麼銜接； 3）等我確認後，再給我拍點表、畫風樣張與分鏡，逐關等我確認； 4）全部確認後才開始製作，最後給我 MP4。 所有計算請再驗算一次並列給我看；我確認前請不要開始製作。

④ 社會技巧：你給主題，Claude 先提出核心概念給你選

這一則的重點是「先討論、你定案、才生成」：Claude 要先分析主題、提出可作為核心的概念選項，等你選定並討論完才規劃影片。

/animate 我要做社會技巧教學影片，主題是「[主題，例如：被拒絕時怎麼回應／輪流等待／邀請同學一起玩]」。 【學生能力】[例：理解較慢、需要具體情境與示範、一次只能學一個行為、容易衝動／情緒起伏大] 【我提供的內容】[教學目標／常見狀況描述／教材，沒有的行刪掉；不要寫學生或同學的真實姓名] 【規格】16:9，用貼近學生生活的校園或家庭情境，角色用動物或卡通人物，不使用真實人物；[有／無] 旁白；風格 [剪紙／素描本／由你推薦]。 【流程】請嚴格依序，每一步都要等我回覆才進下一步： 1）先分析這個主題：重要概念有哪些、學生常見的困難、哪些行為要教； 2）提出 3～4 個「可作為影片主要核心的概念」讓我選，每個說明它教什麼、適合什麼樣的學生、可用的情境； 3）我選定後，和我討論並確認課程內容：情境、角色、要示範的正確與不適當的做法、學生要學會的一句話或一個動作、結尾怎麼收； 4）我明確說「規劃確認」之後，才給我拍點表、畫風樣張、分鏡，逐關等我確認； 5）全部確認後才開始製作，最後給我 MP4。 在我說「規劃確認」之前，請不要開始製作影片。

⑤ 溝通訓練（音量、聽不清楚時怎麼問、把話說完整、對話修復）

/animate 我要做溝通訓練教學影片，主題是「[主題，例如：聽不清楚時怎麼請對方再說一次／用適當的音量說話／把一件事說完整]」。 【學生能力】[例：能說短句、不容易主動求助、需要句型範例可以直接照著說] 【我提供的內容】[教學目標／常見狀況／想教的句型，沒有的行刪掉；不要寫真實姓名] 【影片要有】一個學生熟悉的情境、不適當的示範與適當的示範對照、可以直接模仿的「一句話」（字幕大字顯示）、結尾一個「換你試試看」的暫停提示。 【規格】16:9，畫面文字用繁體中文，角色用動物或卡通人物；[有／無] 旁白；風格 [剪紙／素描本／由你推薦]。 【流程】請依序：先分析主題與可教的重點，提出 3 個可作為核心的教學點讓我選；我選定並討論確認後，再給拍點表、畫風樣張與分鏡，逐關等我確認；全部確認後才開始製作，最後給我 MP4。我確認前請不要開始製作。

⑥ 通用範本：其他學科或特教領域（生活自理、情緒調節、IEP 目標、自然、社會…）

換掉括號裡的內容就能用在任何主題。

/animate 我要做一支 [領域／學科] 的教學影片，主題是「[主題]」。 【學生能力】[能力描述，不寫姓名] 【我提供的內容】[教材／教學目標／例題／例句，教材放在資料夾，檔名：…] 【影片目的】讓學生能 [學會什麼，例如：說出語詞的意思／照步驟完成一件事／辨認並說出情緒] 【規格】16:9，長度約 [秒數]，畫面文字用繁體中文，每個畫面一個重點；[有／無] 旁白；風格 [由你推薦]。 【流程】請依序：1）先分析我提供的內容與主題，列出重要概念、學生可能的困難；2）提出影片規劃與難易度設計，並提供 2～3 個核心方向讓我選；3）我確認後，再給拍點表、畫風樣張、分鏡，逐關等我確認；4）全部確認才開始製作，最後給我 MP4。我確認前請不要開始製作。

做完之後：常用的修改句

請把第 [3] 段的字幕放大，句子再短一點，並在重點詞旁邊加上圖示。其他段落不要動，改完重新輸出 MP4。
這支對 [學生能力] 的學生還是太難。請把第 [2] 到第 [4] 段拆成更小的步驟，每段只講一個重點，並把重要的句子重複一次。改完重新輸出 MP4。
請在影片最後加一個「複習與練習」的畫面：列出這次的 [重點] 並出 [3] 題小測驗，每題先出現題目，停 [5] 秒，再顯示答案。
這些提示詞是我依 animate 技能的流程（問答、故事、畫風、分鏡三個確認關卡）設計的版本，提示詞本身尚未在每個科目實際跑過。第一次用建議先挑一個小的題目（單一語詞）測試，再依結果調整難易度描述。

組合技：搭配目錄裡其他技能

animate 負責「動起來」，其他技能負責「內容正確」。下面是幾種搭法（技能名稱都能在目錄查到）。

想做的事搭法
成語說明動畫先用成語教學類技能確認成語意思與例句，再把確認過的文字交給 animate，並要求「畫面文字只用我給的這些」。
課文或單元複習短片把課本截圖或整理好的重點放進資料夾，請 animate 依重點排拍點，配 guoyu-vocab-animated-reader 之類的點讀教材當課後練習。
社會技巧情境情境與題目由 social-scenario-animated-reader 這類技能產出，需要影片版時再交給 animate 做成短片。
簡報裡的動態圖表入門做法產出 MP4，再請 Claude 把影片插進指定頁的標題下方。檔案太大時，改成自己插。
要真人或實拍感animate 做不到，改用目錄裡的 colab-video-gen 之類 AI 生成影片，兩者可剪在一起。
多尺寸發布同一個作品一次輸出直式、方形、橫式，貼到不同平台。
做給學生看的教材，請先把事實、字詞、注音再核對一次，AI 的自我檢查不能取代老師把關。

換電腦、換 agent 能用嗎？疑難排解

只貼提示詞行不行？

入門與中階可以：提示詞是一般文字，任何有 Claude 的地方都能貼。進階不行：/animate 是安裝在電腦上的技能，每台電腦都要各裝一次外掛與環境（Node、ffmpeg、Playwright）。

  • 只有支援 Claude Code 技能格式的 agent 能用；Gemini、ChatGPT 與雲端版 Claude 沒有本機的瀏覽器與 ffmpeg，無法渲染。
  • 其他 agent 若要借用，可把技能資料夾整份交給它讀 SKILL.md，但渲染環境仍然要有。

常見問題

  • 說找不到 playwright：跑工具時加上 NODE_PATH=$(npm root -g)，或請 Claude 代為處理。
  • 工具參數順序：截圖工具 still.mjs 的順序是「作品資料夾、時間點、輸出檔」。
  • riso（孔版印刷）範例在 2 秒處報錯 createRadialGradient：2026-11-21 實測內建 riso demo 會出現，尚未查明原因；其他風格的範例（如剪紙的 history-of-ai）渲染正常，遇到可先換畫風。
  • 它自己多寫了不該有的文字：在提示詞明講「畫面文字只能用我給的這些」。
  • 做出來像會動的投影片：沒有用到工具包，或沒有指定畫風，改用 /animate 並選畫風。

三個心得

  1. 真正花時間的是把需求講清楚。資料、秒數、尺寸都講好，常常一次就過。
  2. 第一版不用太在意，在同一個對話叫它改，通常兩三輪就會是你要的樣子。
  3. 它會自己檢查，但最後一關要你把關，放進正式簡報或教材前，數字與文字務必自己再對一次。
